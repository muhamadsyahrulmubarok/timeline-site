Cara mendapatkan file JSON

Format yang didukung aplikasi:

  • Records.json — Location History klasik dari Google Takeout.
  • Semantic Location History — folder bulanan Takeout (JSON per bulan).
  • Export Timeline dari ponsel — JSON dari Google Maps Timeline di perangkat.

Di Google Takeout, pilih Location History / Timeline, unduh ZIP, lalu ekstrak file JSON-nya. File dibaca di browser — tidak diunggah ke server Timeline.
